# BandBridge IELTS — v3.4

## Run / publish
1. Extract this ZIP into one folder.
2. Open `index.html` in a modern browser, or upload the entire folder contents to GitHub Pages.
3. Keep the `assets/tests/` folder and all HTML, CSS and JS files together.

## Included
- BandBridge IELTS dashboard, profile preferences and local analytics.
- Five supplied Academic Reading PDFs, each with three passages, 40 questions and a 60-minute timer.
- PDF reading pane beside a clean answer sheet. TRUE/FALSE/NOT GIVEN and YES/NO/NOT GIVEN groups use inline radio buttons. Other questions accept a typed answer or answer letter.
- Exit confirmation: unfinished answers are discarded; starting again begins from Question 1.
- Submit, automatic answer-key scoring, indicative band estimate, retake and local attempt history.
- Listening, Writing and Speaking remain marked coming soon.

## Source and scoring notes
- The five uploaded test PDFs and five matching answer-key PDFs are included as provided. The answer keys are used for automatic scoring. Exact text matching may not accept every legitimate spelling or formatting variant; review the supplied answer key if a response is marked wrong unexpectedly.
- Test 4 questions 30–32 are scored as the unordered set B/C/E, matching the printed answer key.
- The band estimate is indicative only, not an official IELTS conversion.
- The PDF pane uses the browser's built-in PDF viewer.

## Data and privacy
- Attempt history is stored in browser localStorage on the same device/browser. There is no login, backend, cloud sync or cross-device history.
- Deliberate Exit discards the unfinished attempt. Completed attempts remain in local history. Clearing browser site data removes that history.

## Attribution / limitations
This is an independent practice interface, not an official IELTS product. The supplied papers are included for the user's private practice workflow.
