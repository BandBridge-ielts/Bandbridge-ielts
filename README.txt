# Bandbridge IELTS — Final Version 3.0

## Run locally
1. Download and extract this ZIP.
2. Keep `index.html`, `style.css`, and `script.js` together in one folder.
3. Open `index.html` in a modern browser (Chrome recommended).

An internet connection is only needed for the optional Google Fonts. The application itself runs locally.

## Included
- IELTS-style dashboard with responsive sidebar/navigation.
- Reading score trend chart based only on completed attempts.
- Question-type accuracy analytics based only on recorded answers.
- Best estimated Reading band, number of completed tests, average accuracy and editable target band.
- Recent Reading activity.
- One available Academic Reading test: 3 original passages, 40 questions, 60 minutes.
- Listening, Writing and Speaking sections marked "Coming soon" / no tests available.
- Grammar and saved vocabulary placeholder sections; no invented lesson or vocabulary data.
- Timed Reading exam, flagging, question navigation, answer explanations, automatic submission and local resume.
- Reading results with indicative band estimate and question-type breakdown.

## Data and privacy
- Test-in-progress answers and deadline are stored in browser localStorage.
- Completed Reading attempt history and profile preferences are stored in browser localStorage.
- No account, server, payment system or cloud sync is included.
- Clearing browser site data removes locally saved progress/history.

## Important limitations
- This is an independent IELTS-style practice resource, not an official IELTS product or official Cambridge test.
- Band estimates are indicative only. Actual Academic Reading conversion thresholds can vary by test form.
- Only Reading Test 1 is available because only one complete Reading question set has been supplied. Listening, Writing and Speaking deliberately show no tests available / coming soon until their content is provided.
- Analytics begin empty and populate from actual completed attempts. No sample scores or fabricated chart data are shown.
